# NoxBot — canal de auto-update

Canal público **solo de binarios** (launcher / bridge / updater).

El motor Lua **no se publica aquí**. Las firmas van en un repo privado.

## Qué hay
- `update/latest.json` — versión del canal
- `update/files/` — `NoxBotLauncher.exe`, `NoxBotBridge.dll`, `NoxBotUpdater.exe`

Versión actual: **4.0.0**
